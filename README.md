# 刷题助手（local-Learning-Hub）

一个篡改猴（Tampermonkey）脚本，把学习通的题目交给**你自己部署的模型**来分析和预填，支持本机与局域网 OpenAI 兼容接口。

基于 [zhu-hailin/chaoxing-ai-assistant](https://github.com/zhu-hailin/chaoxing-ai-assistant) v1.33.4（MIT）二次开发。

## 安装

1. 安装 [篡改猴 Tampermonkey](https://www.tampermonkey.net/)
2. 浏览器扩展管理页里，打开篡改猴的「**允许运行用户脚本**」开关（不开启脚本不会运行）
3. 点击安装：[刷题助手.user.js](https://raw.githubusercontent.com/maplewindio/local-Learning-Hub/main/刷题助手.user.js)
4. 打开学习通作业页，右侧会出现助手面板，标题为 `刷题助手`

## 配置

| 项 | 说明 |
|---|---|
| 服务商 | 选「自定义」 |
| 接口地址 | `http://127.0.0.1:3425/v1`（本机）或 `http://192.168.x.x:3425/v1`（局域网） |
| 模型 ID | 点「获取模型」后选择 |
| API Key | 先保存接口地址，再保存 Key（Key 与地址绑定，顺序反了会报 401） |
| 深度思考 | 支持开关与强度 low / high |
| 分析并发 | 本地服务建议 3，过高容易触发超时 |

局域网访问时，模型服务需监听 `0.0.0.0`，且两台机器在同一网段。

## 与原版的主要差异

- 自定义服务商放开 http，支持本机与局域网私有地址（127.x / 10.x / 192.168.x / 172.16–31.x / ::1）
- 自定义服务商开放深度思考与推理强度参数
- 3 题一批打包请求，减少重复系统提示词开销
- 主按钮「重新分析全部」只补未完成的题，不再整卷重跑
- 重试固定 3 并发、3 题一组
- 部分题目失败也允许预填已完成的题目；批次内已答对的答案不再被连带丢弃
- 失败题支持「手动填答案」，手填结果参与预填
- 更新检查指向本仓库 main 分支

## 发版与更新

更新脚本头部的 `@version` 后推送到 `main` 即可。客户端「检查更新」会读取本仓库 main 分支的脚本版本号，检测到更高版本时提供下载链接。

## 风险

自动分析与预填会操作你的真实学习记录，AI 也会答错。提交前请自行核对。本工具不提供考试功能，仅用于作业与练习场景。
